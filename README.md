to build and run the contents of this repository `"npm install"` then `"npm start"`

### ambient-weather-api
- refer to https://github.com/ambient-weather/api-docs/wiki/Device-Data-Specs for soil info

    - soilhum1...soilhum10 - Temperature 1...10, %
    - soiltens1...soiltens4 - Soil Tension 1...4, Float, cb
